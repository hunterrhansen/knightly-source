# Daily practice home

Accepted. Home focuses on the chess learning loop, following
[Knightly direction](../knightly-direction.md).

Show the streak and account controls, the daily session with completed/total
positions and estimated duration, and a direct Start/Continue practice button.
When the plan recommends a game, open its review directly. Keep Practice
reminders available without a path-node sheet. Games and Progress live in the
main navigation, without duplicate buttons on Today. A completed session shows
saved status, the next remaining review and optional additional practice.
New accounts can connect games; processing, empty, loading and failed states
remain explicit and recoverable.

No journey map, castles, posts, ranks, locks, character or landscape is part of
home. Old `/node` links return home. The backend's plan, teaching sequence and
learning history remain authoritative; this presentation change does not reset
progress or alter answer submission.

Native uses the shared page header and existing streak/account toolbar controls.
Web shows the streak in the page and the account action in the shared shell.
Home is scrollable for narrow screens and larger text. Games and Progress are
peer tabs; Account retains its modal navigation and return behavior.
